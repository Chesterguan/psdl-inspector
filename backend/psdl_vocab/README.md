# psdl-vocab

Enriched OMOP vocabulary + searchable service for the PSDL ecosystem.

Embedded in psdl-inspector (concept lookup + terminology anchoring) and psdl-workbench
(live vocabulary search + datasetSpec binding). Ships with a bundled enriched OMOP JSON
file; override with `PSDL_VOCAB_DATA_DIR` to point at a custom vocab build.
